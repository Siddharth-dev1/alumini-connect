# Alumni Connect

A platform connecting students and alumni for networking, mentorship, career opportunities, and events.

## Features
- Student and alumni accounts
- Alumni directory
- Mentorship
- Jobs and internships
- Events and notifications
- Messaging and connections
- Admin dashboard

## Technology Stack
- React and Vite
- Node.js and Express.js
- Database configured by the project

## Setup
1. Install the frontend dependencies: `cd frontend && npm install`
2. Install the backend dependencies from your backend folder using `npm install`.
3. Configure the environment variables required by the application.
4. Start the frontend and backend using the scripts in their respective `package.json` files.
